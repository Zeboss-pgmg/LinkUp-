UN COUP DE MAIN

Prendre en main SkillSwap.

Comment parcourir les profils ?

Glisse vers le bas pour changer de profil. Glisse vers la droite, ou en diagonale vers le haut à droite, pour retourner la carte. Le geste inverse ramène à la photo. Sur ordinateur, les flèches du clavier fonctionnent lorsque la carte est sélectionnée.

Comment trouver un service ?

Dans Explorer, choisis une catégorie ou cherche une compétence. Le signet permet de garder un favori, à retrouver dans ton profil.

Mes messages sont-ils réellement envoyés ?

Non. Cette version scolaire est une démonstration locale. Les profils, messages et réservations sont fictifs. Aucun service réel n’est réservé et aucun point n’a de valeur monétaire.

Installer sur iPhone

Ouvre le site dans Safari, touche Partager, puis Sur l’écran d’accueil. Une fois les ressources téléchargées, la version web peut se rouvrir hors connexion. L’installation web est distincte d’une publication sur l’App Store.

Une nouvelle version est disponible

Le bouton Mettre à jour apparaît lorsqu’une mise à jour de l’app web est prête. Termine tes saisies avant de l’utiliser.

Besoin d’aide pour le projet scolaire ?

Adresse-toi à l’équipe qui t’a transmis cette démonstration. Le bouton Signaler de l’app enregistre une simulation et ne contacte pas de modérateur réel.
